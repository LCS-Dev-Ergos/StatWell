# StatWell security, correctness, robustness, and performance audit

## Revision and scope

Audited on 2026-09-29 on arm64 macOS 27.2 (26B5091g). A fresh fetch confirmed
`origin/main` at `1812c417f92f2d5a192284f8b9b35f9a6542590a`, the merge of
[PR #5](https://github.com/LCS-Dev-Ergos/StatWell/pull/5). Its
[CI run](https://github.com/LCS-Dev-Ergos/StatWell/actions/runs/36619504196)
passed. The primary checkout was still at `5213cac`, with local changes to
three `.vscode` files. The audit used an isolated worktree on
`lcs-code/audit-20260929`; those local changes were preserved.

Scope includes CLI schemas and error behavior, typed calculations, native
macOS probes, Linux procfs/sysfs readers and parsers, Homebrew/pacman workers,
daemon scheduling, snapshot transport, SketchyBar events, launchd/systemd,
Home Manager, CMake/Nix packaging, and CI. The Nix package-update provider
remains excluded. A stable release is not approved by this report.

## Reproduced findings and corrections

P2 denotes a defect to correct before stable release. P3 denotes a lower
frequency edge case. No P0/P1 finding was demonstrated in the covered paths;
this is bounded audit evidence, not a claim that every possible input or host
has been examined.

| ID | Severity | Reproduction and effect | Correction and regression |
| --- | --- | --- | --- |
| A01 | P2 | A FIFO named `daemon.lock`, or `snapshot.json` with a held regular lock, blocked `snapshot` beyond a 700 ms diagnostic deadline. File type was checked only after blocking `openat`. | Open candidates with `O_NONBLOCK` before inspecting type. `runtime_security_contract.py` requires prompt rejection of both FIFOs. |
| A02 | P2 | A hard link from `daemon.lock` to an external same-user file changed that file's mode from `0644` to `0600` when the daemon started. | Require a single link before `fchmod`, and apply the same condition to lock readers. The regression verifies rejection and unchanged bytes/mode. Final directory symlinks, including a trailing slash, are rejected too. |
| A03 | P2 | Concurrent Homebrew/pacman workers inherited the other worker's pipe endpoints in 25/25 diagnostic runs. Observed descriptors were `[5, 6]` and `[3, 4]`. A leaked write endpoint can delay EOF and create a false timeout. | Linux uses atomic `pipe2(O_CLOEXEC)`; macOS uses `POSIX_SPAWN_CLOEXEC_DEFAULT`. A concurrent-provider regression checks that no pipe descriptors survive exec. |
| A04 | P2 | A provider wrote valid JSON, closed stdout, then slept 0.8 s. StatWell used 0.832 s of CPU in 0.842 s elapsed because EOF remained immediately poll-ready. | Stop polling the pipe after EOF while awaiting the child. The corrected Release run used 0.023 s CPU in 0.848 s elapsed; the regression caps CPU use for this case. |
| A05 | P2 | Running StatWell with its stdout closed returned exit 1 for a valid provider. A pipe occupied fd 1, which a spawn close action closed after `dup2`. | Move pipe endpoints above fd 2 before preparing actions, and give the child `/dev/null` stdin. Regressions cover independently closed stdin, stdout, and stderr. |
| A06 | P2 | `Platform.ReadsHighestActiveInterfaceIndex` failed for active `utun4`, index 27. `IFMIB_IFCOUNT` was 27, but the backend scanned indices 0 through 26. Interface count also cannot safely describe gaps in indices. | Resolve the actual name with `if_nametoindex` and query that index. The native regression now passes, and macOS CI runs runtime contracts as well as package builds. |
| A07 | P2 | A checkupdates fixture printing `database sync pending` and exiting 0 reported `status=ok,total=1`. Every nonempty line was counted as an update. | Require four printable tokens with `->` in the third position. Regressions reject diagnostics, wrong arrows, missing/extra fields, and control characters. |
| A08 | P3 | An unchanged watch sample had the same event identity before and after the clock moved behind its value timestamp. Consumers could miss the transition to a future-dated, stale value. | Add a future-date identity and regressions for entry, deduplication, and recovery. This uses supplied times, without changing the host clock. |

The lock/path cases require control of the private runtime directory by the
same UID or a wrongly provisioned directory. No cross-user privilege
escalation was demonstrated. Files owned by another UID and modes outside
the private-directory/file contract remain rejected. The transport is not a
security boundary against another program running as the same user.

## Verification

The baseline passed its original five CTest targets. New regressions were run
before their respective corrections: FIFO reads timed out, the provider CPU
assertion measured 0.829 s, the native interface test failed on `utun4`, the
malformed pacman fixture reported one update, and the clock transition had
identical identities. All six final CTest targets pass in these local profiles:

| Profile | Toolchain | Result |
| --- | --- | --- |
| Debug | Clang 23.1.0 | 6/6 |
| ASan/UBSan | Clang 23.1.0 | 6/6 |
| ThreadSanitizer | Clang 23.1.0 | 6/6 |
| GCC Debug | GCC 16.2.0; GoogleTest built from source with the same compiler | 6/6 |
| Nix CI environment, Debug | Clang 21.1.8, Python 3.14.7 | 6/6 |

Reproduction commands for the retained regressions are:

```sh
make test PROFILE=debug
make test PROFILE=asan
make test PROFILE=tsan
make test PROFILE=gcc GTEST_SOURCE_DIR=/path/to/googletest
builds/debug/statwell_tests --gtest_filter='Platform.*:Watch.*'
python3 tests/runtime_security_contract.py builds/debug/statwell
python3 tests/packages_contract.py builds/debug/statwell
```

`make format-check`, `git diff --check`, and `make tidy PROFILE=debug` pass.
Clang-tidy reports no project findings; system-header warnings are suppressed
by the existing configuration. The pinned CI shell's
`cppcheck --enable=warning,style,performance,portability --error-exitcode=1
--std=c++23 -I include src` also passes.

The daemon contract now uses four simultaneous client workers for 12 reads.
It checks owner-only modes, duplicate instances, sampling cadence, SIGTERM,
crash recovery, and restart. A deterministic SIGSTOP/SIGCONT cycle waits for
the stopped state, confirms an unchanged snapshot during suspension, and
requires a publication after resume. It does not simulate kernel sleep or
physical device reconnection.

The provider contracts cover fixed arguments, zero/update/error behavior,
invalid and oversized output, missing executables, deadlines, worker
isolation, cancellation on daemon shutdown, and retained last valid values.
Homebrew JSON is bounded by a 4 MiB output cap and depth limit; pacman lines
are limited to 4,096 bytes. Commands run without a shell, in their own process
groups. The [checkupdates contract](https://man.archlinux.org/man/checkupdates.8.en)
documents old/new version output and exit 2 for no updates. The
[Linux pipe documentation](https://man7.org/linux/man-pages/man2/pipe2.2.html)
and [spawn documentation](https://man7.org/linux/man-pages/man3/posix_spawn.3.html)
support the descriptor lifetime checks. A real Homebrew check with
`HOMEBREW_NO_AUTO_UPDATE=1` matched a direct `brew outdated --json=v2` read:
zero formulae, zero casks, zero total. Live pacman metadata on Arch remains
unverified.

### Services, packaging, and CI

Source review confirms opt-in user services with fixed/escaped executable
arguments, `gui` launchd domain without a Background session restriction,
and systemd failure restart. Home Manager checks enforce absolute configured
paths, valid cadences, and enabled provider names. No service was activated
by this audit.

`nix flake check --all-systems --no-build` evaluated both supported systems.
`nix build .#statwell .#checks.aarch64-darwin.home-manager --no-link` built
the corrected macOS package and Home Manager generation. CMake installation
into a temporary prefix passed, and a separate CMake application imported
`StatWell::statwell_core`, linked it, and generated a one-shot snapshot.
Service templates embed `CMAKE_INSTALL_PREFIX` at configure time; installing
with a different `cmake --install --prefix` does not rewrite their paths.
README wording now makes that limitation explicit.

CI retains read-only repository permissions, pinned action commits, disabled
checkout credential persistence, and bounded job timeouts. This branch adds
macOS Debug and ASan/UBSan runtime contracts; Linux retains package/Home
Manager builds and Clang Debug, ASan/UBSan, and GCC contracts. Hosted results
for source commit `252f19b58cbe1c52e3860df0a5391e0a6453b2ea` passed in both
the [push run](https://github.com/LCS-Dev-Ergos/StatWell/actions/runs/36628444899)
and the [PR run](https://github.com/LCS-Dev-Ergos/StatWell/actions/runs/36628510265).
Ubuntu 24.04 passed package/Home Manager builds and all six targets in Debug,
ASan/UBSan, and GCC. macOS 15 passed package/Home Manager builds and all six
targets in Debug and ASan/UBSan. The corrections are published in
[PR #6](https://github.com/LCS-Dev-Ergos/StatWell/pull/6), pending integration.
Hosted Ubuntu evidence does not verify the physical Arch deployment.

## Performance

The short Release run used default cadences, `en0`, no package provider,
a separate runtime directory, two seconds of warm-up, and 30 one-second
`ps` observations. CPU median was 0.0% (maximum 0.7%); RSS median was 4,864 KiB
(maximum 5,040 KiB). Snapshot read/JSON parse median was 73.9 µs for 200
reads; snapshot CLI median was 4.93 ms for 20 processes. Results and method
are in [performance.md](performance.md#2026-09-29-audit-run).

Twenty-one newly observed publications had a capture-to-observation median
of 5.26 ms, maximum 7.62 ms, with five-millisecond reader polling. That
interval includes serialization, publication, polling, and reader work; it
does not isolate `fsync`/rename duration. Host load and process accounting
vary; the one-minute load at the end was 14.15. Some local build activity
overlapped the run. Differences from the earlier short baseline are not a
controlled regression comparison or evidence of long-term power usage.

## Residual release gates

1. Merge the corrections after hosted Linux/macOS checks, update the Dotfiles
   pin, build/switch the intended generation, and verify consumer rollback.
2. On the physical Legion, build/switch Home Manager, observe the systemd
   user service and Kitty surface, compare native probes and live pacman
   results, and measure Linux performance/publication behavior.
3. Reboot macOS and verify automatic GUI agent loading and widget recovery.
   Exercise long-duration sleep/wake, network interface changes, battery
   discharge, memory pressure, and abrupt power/process interruption.
4. Measure publication syscall cost and worst-case behavior separately from
   reader polling; retain the short observed interval as a bounded host sample.
5. Make an explicit stable-release decision only after these deployment and
   long-duration gates have evidence. This audit creates no stable tag.

The snapshot client intentionally validates the version prefix, ownership,
modes, and size; it is not a full JSON validator. Direct consumers must parse
JSON and validate freshness as specified by the protocol. OS reads are
bounded in bytes but calls such as `statvfs` on a stalled remote filesystem
are not given a time deadline; the default local disk path avoids that
configuration. These limitations remain explicit in the release assessment.
